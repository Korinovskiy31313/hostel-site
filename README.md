# Hotel Horizon

Навчальний статичний вебсайт готелю для лабораторних робіт з вебадміністрування.

## Призначення

Сайт містить головну сторінку Hotel Horizon та окрему сторінку з категоріями номерів. Проєкт призначений для відпрацювання Git, Docker, Nginx та розгортання на Render.

## Структура

- `index.html` — головна сторінка.
- `rooms.html` — сторінка з номерами готелю.
- `styles.css` — стилі сайту.
- `Dockerfile` — створення контейнерного образу на базі Nginx.
- `nginx.conf` — конфігурація Nginx для порту 10000.
- `.dockerignore` — файли, які не копіюються до контексту збирання Docker.

## Локальний запуск без Docker

Відкрийте `index.html` у браузері або запустіть локальний HTTP-сервер.

## Збирання та запуск Docker

```bash
docker build -t hotel-horizon .
docker run --rm -d --name hotel-horizon -p 8080:10000 hotel-horizon
```

Відкрийте `http://localhost:8080`. Зупинити контейнер можна командою:

```bash
docker stop hotel-horizon
```

## Розгортання на Render

Підключіть GitHub-репозиторій `hotel-site` до Render, створіть Web Service, виберіть гілку `main` та середовище `Docker`. Render збирає образ з `Dockerfile` у корені репозиторію. Nginx слухає порт `10000`.
